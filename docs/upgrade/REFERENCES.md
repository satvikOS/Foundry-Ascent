## Client authority

`docs/blueprints/02_Ain_Foundry_vEIR_Product_and_Operating_Blueprint.pdf` (September 2026), all 18 pages extracted and inspected. Sponsor briefing `Downloads/virtual_eir_briefing.pptx.pptx`, all eight slides’ text extracted and inspected. The briefing explicitly defines Diagnose, Coach, Record; three models; the five-step loop; four persistent artifacts; four intake routes. It specifies only the evidence-ladder endpoints. Intermediate rung names and thresholds still need client ratification. The application describes actual evidence without manufacturing six established definitions.

## Tokens and artwork

`apps/web/src/styles/globals.css` is the shared source for palette, semantic state, glass fallback, type, spacing, radii, elevation, focus and motion. New `--presence-*` tokens are reserved for the original surrogate artwork; `--voice-accent-*` is reserved for the bounded voice sphere. Existing self-hosted Geist/Newsreader are retained (both installed LICENSE files inspected); installed LiveKit retains Apache 2.0 licensing. Original inline SVG character is project-authored, implies no real person's likeness, and adds no asset or dependency license obligations. LiveKit remains lazily loaded only for remote video.

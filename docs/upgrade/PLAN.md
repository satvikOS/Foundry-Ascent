## Product findings

The approved September product blueprint provides the five-object substantive-session contract, continuity, governed memory, and escalation. It does not define a six-rung evidence ladder. The supplied request establishes assertion and retained behavior as endpoints; intermediate names remain unapproved. We will not invent them. Current implementation has six coaching skills; Diagnose, Coach, Record will remain operating responsibilities, without erasing existing useful rehearsal/teaching/routing skills.

AI candidates are currently auto-confirmed, conflicting with the current approval requirement. A local abstract presence is not a live character.

Restore explicit pending memory review. Calls gain a presentation choice between a focused sphere and an original lightweight live character. State text and controls stay visible. Review against brief: no hero rebuild, repeated metric cards, neon dashboard, or new service. Small controls become easier to discover through named choices, pending review and focused context.
